Setup guide

Three platforms, same idea: install a userscript manager once, add our script, then open the casino and refresh. Pick your tab.

🖥️
Works on any Chromium browser — Chrome, Edge, Brave, Opera. You'll install the Tampermonkey extension, flip one required switch, then add the script.
  1. Install the Tampermonkey extension

    Open the Chrome Web Store and click Add to Chrome (the same button works in Edge, Brave and Opera). Pin the icon so you can find it.

    Open Chrome Web Store ↗
  2. Open the extension's settings

    Right-click the Tampermonkey icon near the address bar and choose Manage extension.

  3. Turn on “Allow User Scripts”

    On the extension page, scroll down and switch Allow User Scripts on. Chrome requires this — without it, no script can run.

  4. Install the Desktop script

    Click the button below. Tampermonkey opens its install page — review it and click Install.

    ⬇ Desktop script
    Install Desktop bundle .user.js
    Install page didn't open? Add it manually →

    Right-click the button above → Save link as… to download the .user.js file. Then click the Tampermonkey icon → Create a new script…

    Delete the template, then drag your downloaded file into the editor and save with File → Save (Ctrl+S).

  5. Open the casino and refresh

    Go to Stake, Nuts or Shuffle and reload the page once. The tool panel appears automatically on supported game pages.

    stake.com / .us nuts.gg shuffle.com
    ⚙️
    Turn tools on or off from the gear icon. Once the script is running, a gear icon sits in the bottom-left corner of the page. Click it to open the tools panel, where every tool has its own on/off switch — plus Enable matched and Disable all shortcuts at the bottom.
    ⚡
    Or use the per-tool quick toggles. On each game page, small chips appear just above the gear icon — one per tool for that game. Click a chip to instantly load or unload that tool with no menus (green = on, grey = off).
    🛑
    Only if you really want to switch the whole thing off: click the Tampermonkey icon → Dashboard, then flip the on/off switch next to the script. (The gear and chips above are the easy day-to-day way — this disables everything at once.)

Android needs Firefox — Chrome on Android can't run extensions. You'll add Tampermonkey inside Firefox, then install our script.
  1. Install Firefox from the Play Store

    Get Firefox Browser by Mozilla — the regular one. Not Firefox Focus, not Firefox Beta; only the standard Firefox supports extensions.

  2. Open Firefox's Extensions menu

    Tap the ⋮ menu (top-right) and choose Extensions.

  3. Tap “Find more extensions”

    Scroll to the bottom of the Extensions page and tap Find more extensions.

  4. Search for Tampermonkey and add it

    Type Tampermonkey, tap the first result, then on the add-ons page tap Add to Firefox and confirm.

  5. Confirm Tampermonkey is ready

    Open ⋮ → Extensions again and tap Tampermonkey. Its dashboard opens — that's where every script lives.

  6. Install the Mobile script

    Tap the button below. Tampermonkey opens its install page — tap Install.

    ⬇ Mobile script
    Install Mobile bundle .user.js

  7. Open the casino and refresh

What's inside the bundle

One install gives you every tool below. They switch on automatically on the games they support, and each has a small draggable panel you control.

🔒

Auto-Vault

Credit to Ruby (of StakeStats) for the Stake autovaulter. The Nuts version is basically a direct port over.

Set your Save % (the cut of profit to send to the vault) and hit Start — the tool quietly moves that percentage to the vault at every Check Interval, so you literally can't lose those gains back to the site. Runs headless in a small draggable panel with a live Activity log so you can see exactly what it's doing, when.

Got a spike? The Big-win Threshold (x) defines when a win counts as a big win (anything at or above that multiplier), and the Big-win Multiplier boosts the vault % on those hits — so when you actually stack a big multi, you lock in proportionally more of it instead of letting the base % do the same job for a 100x as a 2x.

🎲

Dice

Manual

Self-explanatory, only it allows you to run Dice on auto using the tool-injected Start button. This gives you the flexibility of adjusting your bet size on the fly, or switching the over/under without interrupting the tool's injected version of autoplay.

IOW

Allows you to set an increase percentage to your bet after a win, and a number of losses in a row before resetting back to base bet. You can also set the number of wins needed (before the loss reset occurs) to reset back to base bet. If you hit the win-reset value, the HUD will flash, letting you know you hit the win reset each time. You may also adjust your bet on the fly without interrupting the tool's injected version of autoplay.

Smart

Smart primarily calculates bet size from three user-facing factors: the user-selected multiplier, the current balance, and the user-selected Aggression value. The Aggression State statistic and Momentum Window statistic also play a role in the calculation. Those state rules are hardcoded, but they are heavily influenced by the selected Aggression value and selected multiplier. The Aggression State can be locked to any of the five aggression states; locking the state also locks the Momentum Window for that specific multiplier, Aggression value, and Aggression State combination. Just set these three values to your liking, and send it. Recommended aggression values sit between 1 and 2. But you can do what you want. Anything above a 2 on the aggression slider is typically set in tandem with a "Take Profit %" value, or an "Autostop On Balance" value.

Advanced IOW

Inspired by SWALD BANKMAN-FRIED's (of StakeStats) 8.47 dice strategy. This mode gives you the ability to easily create your own 8.47 style of strategy on Stake or Shuffle.

Equipped with 2 separate simulators. The main simulator is for testing your own input values. The optimizer simulator allows you to enter value ranges for each parameter — a simulation with each value combination within your set ranges will be run a number of times depending on how many "Trials per combo" you have set.

The results of these trial runs will be on the Results tab. From there you can examine the stats of each combination. You can sort the results by any category, or you can see which combination was best overall by sorting by Score (the default sorting method). When you find a combination you like, you can apply that selected strategy to the Calculator (first tab) for further testing of that individual strategy using your own balance with Simulation Controls.

If you want to use that strategy for real, you can import it into the game by selecting Import New Strategy at the bottom of the Calculator page. This will create the strategy in your game. Be sure to always click the Update Strategy button located on the Stats tab's control deck before a run, and after each profit stop.

Mines

For auto players

Set your preferred amount of mines in the native game. Set your preferred min and max range of tiles to click, and the tool will randomly pick somewhere in that range every round, auto-cash out, and run it back until you stop. Projected Ranges show you the min and max multipliers you can hit based on your selected mines amount, and your min and max range of tiles to click. Additionally, a min and max payout projection will also be displayed in reference to your bet size.

For manual players

Live stats are displayed right on the panel. Current Multiplier, Payout, and Next Gem Chance — the exact probability of the next tile being a gem, computed from how many mines and how many tiles are left on the board.

Keno

Saves and reloads number presets so you can return to common boards quickly without rebuilding the same picks every session.

Presets can include the selected risk or difficulty.
