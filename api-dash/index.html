01 / What it does

What it does

Strategies on every game

Build a strategy the way you would on dice: a base bet, then rules for what happens after a win or a loss. Then run it on keno, tower, snakes or any other game in API Dash. Each game keeps its own strategy, so switching games never mixes them up.

Live statistics

See how a run is going while it runs. Your hit rate and average win sit next to what the odds say they should be, so you know whether you're running hot or cold. A balance graph and a full bet log update with every bet.

Fast betting

No clicking. Bets go out back to back, far faster than you could place them by hand, and the run stops as soon as it hits one of your limits: a loss, a profit or a target balance.

04 / Read this first

Read this before you use it

It bets real money. Sweeps Coins are redeemable and every stake.com currency can be withdrawn. Simulated mode is the only way to run it without staking anything.
Automated play is against Stake's terms. It breaks clause 8.2(c) of the stake.us terms, and an account caught doing it can be closed with its balance withheld. That risk is yours.
No strategy beats the house edge. Betting faster only loses faster. API Dash changes how quickly and precisely you act. It never changes the odds.
There's no warranty. The sites can change their APIs at any time. The app stops when it sees something it doesn't understand, but nothing is guaranteed.
Adults only. At whatever age your country or state sets, and only with money you can afford to lose.
