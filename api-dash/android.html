Release notes

01 / Install

Install it

  1. Download the file

    If your browser warns about this type of file, choose to download it anyway.

  2. Open it and tap Install

    Android asks whether your browser may install apps. Allow it, go back, and tap Install. If Play Protect says it doesn't recognise the app, that's because it isn't from the Play Store.

  3. Paste your key

    Open API Dash, paste your key and tap Save key.

  4. Open a site and log in inside the app

    Use your email and password: "Sign in with Google" doesn't work inside apps. If the site asks you to verify you're human, tick the box.

⚠️
A run only goes while you can see it. Locking the screen, switching to another app or hiding the panel stops the run, the same as pressing Stop. When you come back, the panel says why it stopped. The screen stays on while a run is going.
