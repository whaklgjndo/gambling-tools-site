API Dash on iPhone

There's no App Store app, because Apple only accepts real-money gambling apps from licensed casinos. API Dash runs in Safari instead, through the free Userscripts app. Setup takes about five minutes, and you only do it once.

01 / Setup

Set it up

  1. Install Userscripts

    It's free on the App Store, by Justin Wasack. Open it once: it makes its own folder in Files, under On My iPhone › Userscripts.

  2. Turn it on in Safari

    Settings › Apps › Safari › Extensions › Userscripts (on iOS 17 or older: Settings › Safari › Extensions › Userscripts). Switch on Allow Extension and set All Websites to Allow.

    ℹ️
    Why all websites? Your dashboard comes from the API Dash licence server, which is a different website from the casino, and Safari only lets Userscripts reach sites it's allowed on. API Dash itself only runs on stake.us, stake.com and nuts.gg.
  3. Open the loader in Safari

    Tap the button below. Safari opens the loader as plain text. That's what should happen, you don't need to read it.

    ⬇ iPhone loader v1.0.6
    Install the loader .user.js
  4. Open the extensions menu

    With the loader showing, tap the extensions (puzzle-piece) icon next to the address bar. On most iPhones it sits at the bottom left; if your address bar is at the top, look for it up there.

  5. Choose Userscripts

    In the menu that pops up, tap Userscripts.

  6. Tap "Tap to install"

    The Userscripts panel opens with a yellow Userscript Detected, Tap to install banner. Tap it.

  7. Slide up, then tap Install

    On the install sheet, press and slide up to reveal the buttons, then tap Install. A green Userscript Installed banner means it worked. Tap the blue checkmark to close the panel.

    The pictures are from the free Gambling Tools bundle, which installs the same way. Yours says API Dash.

  8. Open the casino and paste your key

    Open stake.us, stake.com or nuts.gg in Safari. A sheet asks for your key the first time. Paste it and tap Save key.

No install banner? You can download the file instead and, in the Files app, move it from Downloads into On My iPhone › Userscripts.

⚠️
A run only goes while you can see it. Locking the screen, switching apps or hiding the panel stops the run, the same as pressing Stop. When you come back, the panel says why it stopped.
02 / Good to know

Good to know

You can add time from the panel. Tap Time left at the top of the panel, or Add time in the account sheet. On a site you have no time on, API Dash shows Add time instead of the dashboard, and loads the dashboard once you come back with time bought.
Don't rename the script. Userscripts stores your key under its name, so a renamed script counts as a new phone.
Dashboards update themselves. If the loader itself changes, install it again from this page the same way. Your key stays.
Set it up before by moving the file into Files? You don't need to change anything. To switch to the installed version, delete apidash-loader.user.js from the Userscripts folder first, then use Move to a new device on the store page so the new install can use your key.
To change your key, open stake.us/#apidash-key, or the same address on the other sites.
