Release notes

01 / First run

First run

  1. Windows will say "Windows protected your PC"

    The app is not code-signed, so Windows does not recognise it. Click More info, then Run anyway. If that bothers you, don't run it. That's a reasonable call.

  2. Paste your key

    It looks like SD-XXXXX-XXXXX-XXXXX-XXXXX. The sites you have time on unlock straight away.

  3. Open a site and log in inside the app

    The app keeps its own browser and its own login. Your normal browser is never used or read.

  4. Click the dashboard button in the corner

    The first time, a short walkthrough shows you around. The ? button in the panel's header brings it back.

02 / Good to know

Good to know

stake.us needs a VPN in some regions. It has to be a system VPN. A VPN extension in your browser can't reach the app, which has its own browser.
Closing never cuts a run off. Closing a window or going Home asks first, then stops the run cleanly. A bet already sent can still settle.
Dashboard updates come to you. When a newer dashboard is out, the window offers Restart to update. New versions of the app itself are downloaded from this page, and your key and logins stay.
If it won't start, install Microsoft's Evergreen WebView2 Runtime. Windows 11 and most Windows 10 installs already have it.
