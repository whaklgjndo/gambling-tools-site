# Gambling Tools — Setup Guide

A simple, step-by-step walkthrough for installing the Gambling Tools userscript bundle on **Desktop**, **iPhone/iPad**, and **Android**, with an overview of every included tool (Auto-Vault, Dice, Limbo, Mines, Keno).

**Live site:** https://whaklgjndo.github.io/gambling-tools-site/

Static site served via GitHub Pages from the repository root — `index.html` plus `assets/`, the installable `.user.js` bundles, and the guide screenshots.
